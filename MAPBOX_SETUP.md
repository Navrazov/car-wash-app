# Настройка карты филиалов с OpenStreetMap

Карта теперь использует бесплатный OpenStreetMap через библиотеку flutter_map.
API ключи и регистрация не требуются!

## 2. Добавление координат к филиалам

Вам нужно обновить API или базу данных, чтобы каждый филиал имел поля `latitude` и `longitude`.

Пример JSON структуры для филиала:
```json
{
  "id": "1",
  "name": "Автомойка на Тверской",
  "address": "ул. Тверская, 15, Москва",
  "phone": "+7 (495) 123-45-67",
  "workingHours": "09:00 - 21:00",
  "latitude": 55.7642,
  "longitude": 37.6026
}
```

## 3. Настройка Android (при первой сборке)

При первой сборке для Android автоматически создастся `AndroidManifest.xml`.
Убедитесь, что он содержит необходимые разрешения:

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

## 4. Тестирование

После настройки токена и координат:
1. Запустите приложение
2. Перейдите на вкладку "Филиалы"
3. Нажмите иконку карты (справа вверху)
4. Карта должна отобразить маркеры филиалов
5. Нажатие на маркер покажет детали филиала

## Важные замечания

- **Полностью бесплатно**: OpenStreetMap не имеет ограничений на использование
- **Надежность**: Стабильная и проверенная временем карта
- **Оффлайн**: Возможность кэширования тайлов для оффлайн использования

## Структура обновленных моделей

- `Location` entity теперь включает `latitude` и `longitude`
- `LocationModel.fromJson()` парсит координаты из API
- Карта использует flutter_map с OpenStreetMap
- Маркеры создаются автоматически для филиалов с координатами
- Нажатие на маркер показывает детали филиала
